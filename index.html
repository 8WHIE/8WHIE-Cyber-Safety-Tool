Security Tips

Practical advice to help you stay safe online.

1. Passwords

Never reuse passwords across different sites. Use a password manager to generate and store strong passwords.

2. Multi-Factor Authentication (MFA)

Enable MFA on all critical accounts (email, banking, social media). Use an authenticator app rather than SMS if possible.

3. Phishing Awareness

Always verify the sender's email address. Do not click links in unexpected emails or messages. When in doubt, navigate to the website manually.

4. Software Updates

Keep your operating system, browsers, and applications updated. Enable automatic updates where possible to patch security vulnerabilities quickly.
