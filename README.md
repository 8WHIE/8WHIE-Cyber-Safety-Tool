# 8WHIE Cyber Safety Checklist

**8WHIE — Worldwide Hackers Intelligence & Ethics**

A simple browser-based cybersecurity awareness project.

## Features
- **Safety Checklist**: A 10-point cyber safety checklist with persistent local storage.
- **Password Checker**: A tool to evaluate password strength based on length and complexity (passwords are never stored).
- **URL / Link Safety**: A tool to check links for common suspicious patterns and potential phishing indicators.
- **Security Tips**: Practical, everyday cybersecurity advice.
- **Settings**: Control over application data and local storage.
- Responsive on mobile, tablet and desktop.
- No API, no login, no server, and no personal data collection.

## Run
Open `index.html` in a modern web browser.

## Development and Testing
The project uses standard HTML, CSS, and vanilla JavaScript.
To run unit tests for the core logic:
1. `npm install`
2. `npm test`

## Purpose
This project is designed for defensive cybersecurity awareness and everyday digital safety.
